# Tests automatizados del frontend de Bettson (CyberMariscos)

## Instalación

<details>
<summary>Windows</summary>

```bash
python3 -m venv .venv
.\venv\bin\Activate.ps1
pip install -r requirements.txt
```
</details>

<details>
<summary>Linux</summary>

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
</details>
